# 포즈토키 120개 포즈 구현 및 검증

## 실제 제공 자료

- 기존 AI 생성 예시 21장과 별도로 생성한 새 예시 99장을 연결했다. 120개 이미지 경로와 파일 해시가 모두 다르다.
- 10개 유형에 각각 12장: 서기, 걷기·달리기, 스포츠·춤, 뻗기·굽히기·비틀기, 의자, 바닥·무릎, 눕기, 밀기·당기기·들기, 일상, 감정 표현.
- 거울 반전이나 색상 변경을 추가 포즈로 세지 않았다. 반전은 연습 도구로만 제공한다.
- 새 자료는 내장 image_gen 도구를 사용해 포즈마다 개별 생성했다. 외부 사진을 내려받거나 생성 입력으로 사용하지 않았다.
- 새 이미지 99장의 합계는 약 5.49 MiB, 전체 썸네일 120장의 합계는 약 0.53 MiB다. 목록에서는 작은 썸네일을 지연 로딩한다.

## 사용자 기능

- 유형과 난이도를 골라 연습한다. 포즈 목록에서 이름 또는 PT 번호로 찾고 시작 포즈를 지정한다.
- 한국어, 일본어, 영어, 번체중국어로 포즈 이름·관찰 목표·권장 시간을 제공한다.
- 권장 시간은 안내다. 사용자가 설정한 타이머를 자동으로 바꾸지 않는다.
- 무작위 연습은 최근 관찰한 자료보다 아직 보지 않은 자료를 먼저 배치한다. 사용자가 지정한 시작 포즈가 우선한다.
- 선택한 자료를 모두 본 뒤 반복하며, 묶음 경계에서도 바로 같은 자료를 이어서 보여주는 일을 피한다. 사진 한 장으로 연습하는 경우에는 반복한다.
- 최근 예시 포즈 번호는 최대 120개까지 해당 브라우저에만 저장한다. 직접 고른 사진이나 파일명은 이 기록에 넣지 않는다. 개인정보 안내도 갱신했다.
- 유형·난이도 조합에 자료가 없으면 이유를 표시하고 시작 버튼을 비활성화한다.
- 기존 숫자 포즈 링크는 유지한다. 학습 글의 현재 링크와 캡션은 PT 식별자로 통일했다.

## 이미지 확인

개별 이미지가 보이는 검수용 목록으로 전신 여백, 다른 인물 조각, 자세의 차이, 접지와 도구 사용을 확인했다. PT035·PT041·PT057·PT076·PT090·PT119는 의도와 다른 자세 또는 여백 문제를 발견해 다시 생성했다. PT035와 PT076은 추가 생성 후 발끝이 프레임 안에 들어오는 것을 확인했다.

이 검수는 눈에 띄는 구성·자세 문제를 확인한 것이다. 전문가의 인체 정확도 검수나 실제 학습 효과 검증을 뜻하지 않는다. 모든 자료는 화면에서 AI 생성 예시로 표시한다.

## 확인한 동작

- 자동 검사: 120개 이미지 파일, 120개 썸네일, 중복 파일 해시 없음, 유형별 12장, 4개 언어의 이름과 관찰 목표, 기존 자료 링크 매핑.
- 순서 검사 407개 통과: 한 묶음 안 중복, 최근 포즈 회피, 시작 포즈 지정, 순차 연습, 사진 한 장 반복, 빈 목록 처리.
- 브라우저: 목록 120장, 유형 필터 12장, PT 번호 검색 1장, 검색 결과 없음, 빈 난이도 조합, 시작·종료·복습.
- 실제 두 연습 사이 검사: 눕기 자료 10장을 본 뒤 다음 연습의 첫 두 장은 이전 묶음에 없었던 PT081과 PT074였다.
- 한국어·일본어·영어·번체중국어 표시 확인. 브라우저 오류 로그 없음.
- 390×844 모바일에서 가로 넘침 없음. 눕기 자료의 전신과 연습 조작 버튼을 확인했다.
- 새 학습 글 링크 PT049로 3분·5장·의자 유형 설정 확인. 이전 pose=21 링크가 PT052에 연결되는 것도 확인했다.

## 현재 범위

로컬 구현과 검증을 마쳤다. GitHub 커밋·푸시 및 공개 Vercel 배포는 수행하지 않았다. 다음 확인은 실제 학습자의 사용 반응과 인체 세부에 대한 전문가 검수다.

## 운영 안내 완성 (2026-10-02)

- 운영자는 사용자 요청에 따라 제레미로 표시했다. 한국어·일본어·영어·번체중문에 소개·운영 안내, 개인정보 안내 책임 운영자, 메인과 정보 페이지의 하단 표시를 반영했다.
- 무료·회원가입 불필요·연습 횟수 제한 없음, 광고가 없는 현재 상태와 향후 무료 운영 방향을 설명했다.
- 실제 이미지 확인 범위를 설명하고 전문가의 미술·해부학 검수로 표현하지 않았다. 오류 제보 이후 수정·교체·제외 판단과 주요 변경 내역을 안내했다.
- 실제 문의 이메일이 제공되지 않아 기존 공개 GitHub 이슈를 유지했다. 계정 필요 여부와 공개성, 포즈 번호·기기·브라우저·글 주소 등의 제보 방법을 명시했다. 언어별 제목과 본문을 미리 넣은 작성 링크를 제공하며 자동 제출하지 않는다.
- 메인의 의견 보내기는 선택한 언어의 운영 안내 중 문의 항목으로 연결된다. 개인정보나 개인 사진을 공개 게시하지 않도록 안내했다.
- 최종 자동 점검: 25개 페이지의 내부 링크·자원·앵커 587개, 4개 언어의 운영 안내와 제보 작성 링크, 120개 고유 이미지와 기존 자료 연결, 포즈 순서 407개 검사 통과. JavaScript 문법과 diff 공백 검사 통과.
- 브라우저: 4개 언어의 운영자·운영 안내 표시, 메인 언어 전환 후 문의 앵커 유지, 390×844 모바일에서 가로 넘침 없음, 문의 항목으로 이동과 120개 포즈 목록 확인.
- 화면 증거: `proofs/operations-notice.png`, `proofs/operations-feedback-mobile.png`.
- 커밋·푸시·공개 배포는 보류했다. 광고를 도입할 때 실제 AdSense 계정 연결, 광고 제공자에 맞는 개인정보 안내와 필요한 지역별 동의 설정은 별도 적용해야 한다.
